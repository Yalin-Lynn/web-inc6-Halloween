# 🎃 Haunted Harvest

## Project Overview

Haunted Harvest is a Halloween-themed animated scene created using only HTML5 and CSS3. Our project is based on the **Haunted Halloween Town Square** scene and includes animated Halloween characters, weather effects, animals, and moving objects.

## Scene Option

**Option 1: Haunted Halloween Town Square**

Our scene includes:

- Animated clouds and fog
- Flying bats
- Flying witch
- Trick-or-treaters
- Black cat
- Moving haunted vehicle
- Glowing jack-o'-lanterns
- Moon and haunted house
- Responsive Halloween night environment

## Technologies Used

- HTML5
- CSS3
- CSS Custom Properties
- CSS Keyframe Animations
- CSS Positioning
- Responsive Design
- Git and GitHub

No JavaScript was used in this project.
